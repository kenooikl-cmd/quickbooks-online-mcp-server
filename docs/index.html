AMS MCP for QuickBooks Online

This is a private, internal integration for authorized users. It is not offered as a public accounting service.

AMS MCP connects an authorized local Model Context Protocol client to selected QuickBooks Online companies through Intuit OAuth 2.0.

Account control

Every company connection requires the QuickBooks administrator to approve access. Access can be revoked at any time from the connected QuickBooks account.
